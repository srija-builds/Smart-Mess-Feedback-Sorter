# LLM Cost and Latency Note

The project runs without an API key using a local rule-based fallback, so the demo has no LLM usage cost in offline mode. If an LLM is enabled, cost depends on the chosen model, input/output token volume and provider pricing at the time of use; latency depends on network and provider load. No fixed price or response time is guaranteed. Measure with the approved provider and record model, date, sample size, average latency, failures and estimated cost per batch. Avoid sending identifying student data unless the institution approves it.
